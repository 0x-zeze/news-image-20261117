## How it works

`generate-image.py` draws the 1024×1024 front page with Pillow (offline,
DejaVu fonts) and writes `entry.png`. `main.ts` (Node 22, stdlib only)
copies that PNG to `/output/entry.png` — deterministic, no network.

Run it: `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`
